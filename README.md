# Bike-Sales
Bike Sales Dashboard (Power BI): $85.3M revenue, $32.2M profit, 113K orders, 11.9 avg order qty (2011–2016). Breaks down revenue/profit by category (Accessories, Bikes, Clothing), by country (US, UK, Germany, France), and sub-category order volume, with slicers for age, gender, year, quarter.
